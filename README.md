🛡️ OSCP — Penetration Testing & Exam Preparation

A practical collection of notes, tools, scripts, cheatsheets, reverse shells, enumeration techniques, privilege escalation resources, and useful commands for preparing for the OffSec Certified Professional (OSCP) exam.

This repository is designed as a personal reference and hands-on toolkit for penetration testing labs and OSCP-style environments.

🎯 Purpose

The goal is to keep commonly used penetration-testing techniques and resources organized in one place so they can be quickly referenced during authorized labs, CTFs, and OSCP preparation.

⚠️ Disclaimer

All tools, scripts, techniques, and examples in this repository are provided for educational purposes and authorized security testing only.

Use them only against systems where you have explicit permission to perform security testing. The repository owner is not responsible for misuse or unauthorized activity.
